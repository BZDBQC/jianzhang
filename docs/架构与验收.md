# 架构与验收

## 信息架构

收支概览 → 全部账单 → 统计报表 → 预算管理；管理区包含账户、二级分类、设置与备份。桌面使用侧栏，手机使用底部导航、菜单和固定“记一笔”按钮。

## 数据与持久化

Ledger 包含账户、分类、账单、预算和设置。账户余额由初始余额与所有交易推导。交易金额以整数分存储，转账手续费使用独立金额与支出分类。

IndexedDB 保存本机账本、按云端用户隔离的本机副本、活动账本指针和最近 10 份同步前备份。写入采用序列号及活动指针事务检查，成功提交后才更新界面。跨窗口广播带窗口标识，其他窗口需重新读取；不自动覆盖编辑中的输入。登录和同步均为可选操作，每次同步显式选择来源，不自动合并。云端 PUT 携带期望账号仅作服务器身份匹配检查，身份始终来自服务器会话或可信平台认证头。

手机号验证码使用 HMAC 与原子一次消费，真实发送确认后才激活；会话令牌只保存摘要。短信配置为空时在访问数据库与短信接口前返回 503。生产只接受 `__Host-` Cookie；开发 Cookie 仅限 HTTP localhost。应用入口无需登录，云端 API 仍需认证。

Cloudflare D1 按认证用户 ID 隔离账本。`ledgers` 保存修订号、写入令牌及元信息，`ledger_chunks` 保存按顺序切分的账本 JSON，每个 TEXT 单元低于 D1 大小限制。写入批次在同一事务内更新元信息、删除旧分块并写入新分块；写入令牌和修订号共同阻止并发旧请求覆盖数据。读取也以同一批次取得元信息与分块。

后端检查登录、请求 Origin、请求大小和完整数据引用。所有 SQL 使用参数绑定。备份恢复使用相同验证流程。保存失败保留表单与当前账本，并显示可操作错误。

## 验证记录

已通过 TypeScript 检查、ESLint 和领域单元测试。测试涵盖金额精度、收支与转账余额、组合条件与区间边界、引用及日期校验、分类迁移、手续费迁移、中文 Unicode 分块、CSV 安全转义及 XLSX 数值和字符串类型。

本地浏览器流程通过：三种记账类型、备注多关键词组合、二级分类和金额边界筛选、复制后连续创建、预算保存、刷新持久化、过期修订号 409 且不丢数据、分类增建与已使用分类迁移、手续费统计下钻、XLSX 下载、JSON 下载及恢复、390px 手机宽度无横向溢出。

下载的 XLSX ZIP 完整性、全部 XML 结构和备份笔数另行验证。安卓 APK 通过编译、资源、DEX、签名及 zipalign 检查；Windows 客户端的具体运行与打包结果见其 release 文档。Android 实机和 Windows 10 实机安装未验证。
