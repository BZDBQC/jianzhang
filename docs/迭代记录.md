# 简账测试与迭代记录

## 2026-10-04：连续三轮优化

范围：安卓与 Windows 10 安装入口共用的在线应用。以原有私有 Site 为发布目标，未修改真实用户账本或安装包签名。

| 轮次 | 复现的问题 | 修复与验证 |
| --- | --- | --- |
| 1：录入流程 | 保存并继续后焦点留在按钮；更换转出账户或从支出切到转账时，转入账户可能为空或与转出相同。 | 保存成功后焦点回到金额；账户变化与类型切换均选择不同的有效转入账户，动态选项变化不接受临时空值。独立浏览器复测通过。 |
| 2：备份与导出 | 数组类型的预算月份、分类颜色被正则转换后错误接受；备注中的 U+FFFE/U+FFFF 导致 XLSX XML 无法解析。 | 明确校验字符串类型，拒绝无效数据；导出滤除 XML 禁止字符，保留中文、emoji、制表与换行。新增两项缺陷回归测试，实际解析 ZIP 与所有 XML 通过。 |
| 3：键盘与小屏 | Enter 不提交筛选/常用筛选；关闭弹窗后失去入口焦点；小屏看不到输入错误；图表首次测量或窗口缩小时短暂横向溢出。 | 两种筛选支持 Enter，选择/重置按钮不会误提交；通用表单弹窗恢复入口焦点；错误提示自动滚入可视区域；图表宽度受容器约束。360×640 键盘流程与五种宽度复测通过。 |

验收结果：11 项自动化测试通过，TypeScript 与 ESLint 检查通过。浏览器综合回归覆盖支出/收入/转账、手续费、分类与金额及备注组合查询、Excel 下载、网络失败保留输入及重试、刷新恢复、无效备份拒绝且修订号不变，以及 360/390/412/1366/1920px 布局。使用隔离的本地 QA 数据，测试结束移除本轮测试记录并恢复偏好。独立代码审查通过。

本批次部署结果以 Sites 的版本与部署历史为准。手机视口模拟和桌面浏览器回归不能替代安卓及 Windows 10 实机安装验证；本轮没有重新构建 APK/EXE，共用在线应用更新后原安装入口继续使用同一地址。

## 后续循环执行

每轮读取关联 Site 的最新源码、README 和此记录，核对已修复问题；只有重新复现才重开问题。先检查数据保存和核心记账，再轮换检查分类、组合搜索、统计、预算、导出和操作体验。有同一项目正在执行的维护任务时避免同时修改、推送或发布；保留其他人的未完成工作。

写入、删除、导入、清空测试只使用明确隔离的测试数据库。验证和代码审查通过后再发布至原 Site，并读取部署结果。记录版本、问题、测试证据和未覆盖范围；没有新问题时不制造代码改动。仅在实际改进、故障、执行失败或需要用户决定时通知。

## 2026-10-05 · 免登录本机账本与可选云端登录

按最新要求改为打开即可记账，首屏为真实空账本；本机 IndexedDB 持久保存支出、收入、转账、分类、预算与设置，登录仅用于手动云端同步。同步前选择数据来源并保留最近 10 份备份，退出返回独立 guest 账本，账户的未同步本机副本保留。短信配置按用户要求留空，未配置时明确提示和返回 503；没有真实发送短信。

验证：17 项自动测试；TypeScript 与零警告 ESLint；真实浏览器三种记账、刷新保留、断网保存、自身广播过滤、跨窗 CAS 后账户草稿保留并重读、存储失败保留金额/备注；隔离 mock 云端验证登录不自动上传、退出保留 guest、恢复 dirty 账户副本、409 保留两份数据和备份。生产构建首次完整缓存后离线重开、离线新增与刷新通过，390px 无横向溢出，缓存不含 auth/ledger API。修复了 SSR 全局随机值调用导致的 500，生产首页恢复 200。独立代码与安全审查通过。

当前维护权限基准：应用入口公开且免登录，云端账本依然要求登录并按账号隔离；不要依据早期“私有站点/强制登录”的历史记录恢复旧限制。短信服务未配置，不得加入生产伪验证码或自动购买服务。保留原有维护计划，新增功能继续使用隔离测试数据，不改真实账单。
