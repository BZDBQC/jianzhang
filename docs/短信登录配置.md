# 短信登录配置

当前短信配置留空。应用可以免登录记账；手机号登录显示“尚未配置”，接口返回 503，不发送短信、不生成可用验证码、不伪造成功。只有真实接入短信服务后才能使用手机号登录云端账本。

## 运行环境配置

在原有简账 Site 的运行环境设置中配置下列值。密钥使用服务端机密设置，不写入源码、客户端、日志或安装包。

| 配置名 | 内容 |
| --- | --- |
| `SMS_PROVIDER` | `aliyun` 或 `relay` |
| `AUTH_SECRET` | 独立的至少 32 字符随机密钥，用于手机号与验证码 HMAC；不是短信服务商密钥 |
| `ALIYUN_SMS_SIGN_NAME` | 已审核的短信签名 |
| `ALIYUN_SMS_TEMPLATE_CODE` | 已审核的验证码模板，参数名称为 `code` |
| `ALIYUN_ACCESS_KEY_ID` | `aliyun` 模式必填；仅具备必要短信权限的 AccessKey ID |
| `ALIYUN_ACCESS_KEY_SECRET` | `aliyun` 模式必填；对应密钥 |
| `SMS_RELAY_URL` | `relay` 模式必填；可信服务端 HTTPS 中转地址 |
| `SMS_RELAY_TOKEN` | `relay` 模式必填；至少 32 字符的服务端中转鉴权密钥 |

应用支持中国大陆 11 位手机号，可带 `+86` 或 `0086`。验证码为随机 6 位，保留前导零；5 分钟有效、最多尝试 5 次，一次成功后原子失效。重复发送成功后旧验证码失效。手机号与 IP 使用 HMAC 保存，验证码不明文入库。会话使用随机令牌和 HttpOnly、Secure、SameSite Cookie，30 天到期，退出会撤销当前会话。

短信发送限制：同号码至少间隔 60 秒；同号码每小时 5 次、每日 10 次；同 IP 每小时 20 次；全站每日 100 次。限额包含已预占后发送失败的请求，避免超支；可在确认需求后调整。阿里云返回 `Code=OK` 只表示已受理，不保证手机已收到。请求超时不自动重试，用户等待后再重发。签名及模板要求参见 [阿里云 SendSms 文档](https://help.aliyun.com/zh/sms/developer-reference/api-dysmsapi-2017-05-25-sendsms)，签名使用 [ACS3 V3 规范](https://help.aliyun.com/zh/sdk/product-overview/v3-request-structure-and-signature)。

## 国内中转模式

阿里云中国大陆短信可能限制境外来源 IP。应用运行在 Cloudflare，若直连出现 `isv.DENY_IP_RANGE`，使用国内服务端中转；具体限制见 [阿里云短信错误码](https://help.aliyun.com/zh/sms/developer-reference/api-error-codes)。中转服务需自行配置，当前没有部署或开通收费服务。

应用向配置的中转地址发送 `POST`，携带 `Authorization: Bearer <SMS_RELAY_TOKEN>`，JSON 为：

```json
{"phone":"13800138000","code":"012345","signName":"已审核签名","templateCode":"SMS_已审核模板"}
```

中转需验证 Bearer 密钥，限制请求速率与来源，仅调用真实短信服务，不记录明文验证码，返回 HTTP 200 和 `{"Code":"OK"}` 表示真实短信请求已受理；失败返回非成功码。应用不跟随重定向，10 秒超时。中转和服务商费用由开通者承担。

## 上线验证

配置完成后重新部署，在自有测试手机号验证真实收码、错误码、过期、重发、退出及账号隔离。应用源码与当前自动测试不包含短信服务商凭据，未进行真实发送。更换 `AUTH_SECRET` 会改变手机号账户标识并使旧会话无法匹配；已有手机号账本启用后应保持密钥稳定，轮换前先制定数据迁移并导出备份。
