# 简账 2.0 使用与迁移说明

本文描述简账独立客户端。安装包、SHA-256 清单及实际验证范围以随附的验收报告为准。旧版 1.0.x 启动器不是本文所述的独立客户端。

## 页面与日常使用

| 页面 | 内容及主要操作 |
| --- | --- |
| 首页 | 当月收入、支出、结余，最近账单，预算提醒，记一笔 |
| 账单 | 分页列表、查看/编辑/删除、复制账单、多条件搜索 |
| 报表 | 时间范围、收入/支出趋势、大小类分布、点击下钻账单 |
| 预算 | 月度总预算、大类预算、提醒阈值与实际支出 |
| 管理 | 账户、两级分类、备份/导出/恢复、提醒设置、可选云同步 |

电脑使用侧栏与表格，手机使用底部导航和记账按钮。首次启动直接进入本机账本。记账时选择支出、收入或转账，填写金额、日期、账户、小类和备注；转账还可填写手续费及其支出小类。只有数据库提交成功才显示保存成功；遇到错误保留输入，修正后重试。

转账本金仅改变两个账户的余额，不进入收支报表。手续费计入支出和预算。一笔转账仍只算一笔账单。金额按整数分计算，输入支持最多九位整数及两位小数。账户停用保留历史。

搜索条件可以组合，条件组之间均需满足。同一组可选多个分类或账户；金额支持等于、大于、小于和包含两端的区间。关键词可选择全部包含或任一包含，忽略大小写。日期包含首尾两天。转入账户方向只匹配转账转入。报表、预算下钻包含手续费，按手续费金额及转出账户筛选。

## 旧账本迁移

1. 在原浏览器打开旧版简账，从数据管理导出完整 JSON 备份。
2. 在独立客户端选择导入 JSON，查看笔数、账户、分类和余额预览。
3. 确认整体替换。软件先保留当前账本备份，再以数据库事务替换。
4. 核对笔数、余额、备注和预算；保留原文件和旧浏览器账本。

同包名同签名升级会保留安卓客户端自身数据，不能自动读取浏览器的独立存储。导入执行整体替换，不自动合并；重复导入不会把账单再追加一次。损坏文件校验失败时保留当前账本。替换前备份保留最近十份。

## 导出、容量与数据保留

数据管理导出的完整 JSON 可恢复整本账本；账单页导出的筛选 JSON 只包含查询结果，不能代替完整备份。CSV、XLSX 便于查看和分析。CSV 含中文表头并处理公式注入；XLSX 金额为数值、备注为文本。安卓通过系统文件选择器选定保存位置，电脑使用文件对话框。取消或提交前失败不会修改本机账本；若账本已经提交而旧备份清理失败，会明确显示已保存和清理错误，避免重复操作。

每个本机账本支持 100,000 笔，不限制为 8 MB。云端仍限制为 20,000 笔，完整 UTF-8 上传请求不得超过 8,000,000 字节。超过云端限制仍可本机记账、搜索、统计和导出。超过旧版容量的大型 JSON 仅保证新独立客户端恢复；旧网页和云端仍按旧限制校验。

Windows 数据库存放在用户数据目录，升级和卸载保留账本。Android **卸载或清除应用数据会删除应用私有账本及内部备份**，操作前应把 JSON 导出到应用外保存。内部自动备份不能抵御卸载、磁盘损坏或整台设备丢失。

## 可选云端登录与同步

本机记账不需要账号。仅在使用云同步时输入手机号并接收真实短信验证码。短信服务暂未配置时显示尚未配置，继续使用本机账本；没有默认验证码、万能验证码或模拟登录。

登录仅建立身份，不自动上传。首次同步明确选择本机或云端来源，覆盖前备份。不同账号副本与本机账本隔离。发生版本冲突保留双方数据，重新核对来源后操作；断网、登录过期或云服务错误只影响同步。

## Windows 安装目录保护

正常升级保留账本和安装目录内的用户额外文件。若额外文件与新版程序路径冲突，安装会停止并保留原目录；先把自己的文件备份到其他目录，再重试。

建议使用默认安装目录。安装器会在事务开始前检查程序、个人文件及恢复目录所需的完整路径；目录过长时会明确拒绝，本次不会移动或删除现有安装。请选择较短目录，不要自行删除恢复标记或修改系统长路径设置来绕过检查。

若旧目录存在安装身份标记，但缺少有效的托管文件清单或清单校验失败，新版的同目录升级和卸载会停止。先导出账本，完整备份原安装目录及相邻的 `.__jianzhang_transaction` 恢复目录，再使用原版本的卸载器移除旧安装登记，最后选择空目录安装新版。不要自行删除恢复标记。旧版浏览器账本仍通过 JSON 迁移，迁移前保留原始备份。

## 验证边界

目标系统为 Android 8.0 及以上、Windows 10/11 x64。实际验收使用当前 Windows 11 和安卓 API 26/29/33/35/36/37 模拟器。Windows 10 实机、安卓真机和真实短信发送保留为未验证；模拟器性能结果不作为真机性能结论。最终验收报告与安装包哈希清单是交付依据。
