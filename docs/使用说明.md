# 简账使用说明

## 记第一笔

打开应用并登录，选择“开始我的账本”。在“我的账户”中设置现金、银行卡、微信钱包的初始余额，也可新增账户。点击“记一笔”，选择支出、收入或转账，输入金额，选择分类与账户，填写日期和备注后保存。

支出和收入金额均输入正数，类型决定方向。金额最多两位小数，必须大于零。转账的转出与转入账户必须不同；手续费可选，有手续费时选择其支出分类。

“保存并继续”保留分类、账户和日期，清空金额与备注。“复制记账”保留原记录的内容并创建新记录。修改或删除账单会同步重算余额、统计和预算。

## 查找账单

“全部账单”顶部可直接搜索备注。多个关键词用空格分隔，默认全部包含。“组合筛选”可设置金额等于、大于、小于或区间；区间包含上下边界。选择大类后可进一步选择小类，不选小类则包含该大类全部小类。

不同字段之间同时满足，同一字段多选时任一匹配。日期包含起止两天。账户筛选可区分涉及账户、转出账户和仅转入账户。当前条件显示在列表上方，可逐个移除或清空。常用筛选只保存于当前设备。

从统计或预算进入相关支出时包含转账手续费。相关转账详情仍显示本金，汇总支出只计算手续费。导出表中本金和手续费各有独立字段。

## 管理分类和账户

分类分为收入和支出，各自采用“大类 → 小类”。可新增、改名、选择颜色、调整顺序。删除已有账单使用的分类时必须选择同类型的其他小类进行迁移；删除大类会同时删除其小类及对应预算，账单会保留。

账户初始余额可以为负数。当前余额由初始余额和所有流水计算。停用账户后仍可查看历史账单；请至少保留一个启用账户。

## 统计和预算

统计支持按月、按年及自定义日期。点击大类或小类可查看相关明细。转账本金不计入收支。

预算可设置月度总预算及大类预算；它们分别计算，不相加。可选择 50%、80%、90% 或 100% 的提醒线。超过限额也会提醒，提醒显示在应用内，不是安卓后台推送。

## 导出与恢复

CSV 与 XLSX 可导出当前筛选、本月或全部账单，包含金额、日期、分类、账户、手续费和备注。JSON 是完整备份，包含账户、分类、账单、预算和设置。

在“设置与备份”选择 JSON 备份文件。系统先校验版本、金额、日期、ID 和引用关系，再展示确认窗口；确认后替换当前账本。无效备份不会改变当前数据。恢复前建议先导出一份当前备份。

## 平台要求

Android：8.0 及以上，需要支持 HTTPS 的浏览器；Chrome 提供 Custom Tabs 体验。Windows：10 64 位，具体客户端依赖见安装目录说明。两个平台均需联网登录和保存。未提供离线记账和后台推送。
